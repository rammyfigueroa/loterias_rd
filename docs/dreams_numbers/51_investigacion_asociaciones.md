# Investigación limitada de asociaciones numéricas

## Método y límite

11. No se extrajo una tabla completa ni se combinaron fuentes para reconstruir
una. Los números se mantienen como hechos atribuidos a publicaciones
comerciales; ninguno está autorizado, aprobado o reconocido como dominicano de
origen.

## Resultado

Se investigaron ocho casos, no veinte. Ampliar la lista sin permisos o fuentes
históricas independientes aumentaría el riesgo de reconstruir tablas
comerciales. Las coincidencias no prueban origen; los conflictos no se resuelven
por mayoría; ninguna asociación puede pasar al catálogo o al descifrador.
