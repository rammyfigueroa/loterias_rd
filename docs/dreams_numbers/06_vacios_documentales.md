# Vacíos documentales

## Vacíos críticos

1. No se ha identificado una tabla 00–99 emitida o avalada por una institución
   cultural dominicana.
2. No existe todavía una genealogía verificable de S01–S04.
3. No se conoce la primera publicación dominicana fechada de esas tablas.
4. No se ha demostrado el origen de las listas de nombres y profesiones.
5. No hay corpus autorizado de relatos de sueños dominicanos para diseñar o
   validar el descifrador.
6. No se localizaron permisos para reproducir íntegramente S01–S05.
7. No se ha verificado diversidad regional, generacional o histórica.

## Vacíos por rama

- **Tabla:** cobertura y procedencia de cada asociación 00–99.
- **Diccionario:** significados culturales independientes de la lotería.
- **Descifrador:** ejemplos de negación, ambigüedad, flexión y expresiones
  compuestas producidos por hablantes dominicanos con consentimiento.
- **Tradiciones:** estudios que distingan observación histórica de generalización
  contemporánea.
- **Variantes:** fuentes lexicográficas sobre dominicanismos y relaciones
  semánticas.
- **Numerología:** evidencia de sistemas locales coherentes sobre nombres,
  profesiones, fechas o repeticiones.

  privadas o vendedores, con fecha y cadena de custodia.
- Investigación comparativa con fuentes cubanas, argentinas y napolitanas
  fechadas, únicamente para determinar influencia, no para integrarlas.

## Limitaciones de esta fase

La investigación fue web y documental. No incluyó visita física, entrevista,
consulta a titulares de derechos ni dictamen legal.
