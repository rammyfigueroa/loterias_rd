# Lista de verificación para revisión cultural independiente

## Estado

La revisión cultural independiente **no se ha realizado**. Esta lista debe ser
completada por una persona con competencia demostrable en cultura dominicana y
sin asumir que su evaluación sustituye la revisión jurídica.

Para cada artículo, registrar nombre, rol, experiencia pertinente, fecha,
versión exacta revisada, observaciones y decisión. No modificar el catálogo
antes de documentar el resultado.

## Lista general

- [ ] La pertinencia dominicana está sustentada por fuentes y no solo por el
      nombre del módulo.
- [ ] Cada lugar, período, comunidad o grupo aparece con el alcance correcto.
- [ ] El vocabulario es natural, respetuoso y comprensible en español
      dominicano sin atribuir origen exclusivo sin evidencia.
- [ ] No se generalizan prácticas locales a toda la población, región, clase,
      familia o generación.
- [ ] Las creencias populares se describen con respeto, sin ridiculizarlas,
      patologizarlas ni presentarlas como hechos sobrenaturales comprobados.
- [ ] Tradición, testimonio, interpretación académica y hecho verificable se
      distinguen claramente.
- [ ] Las referencias corresponden a la afirmación y localización declaradas.
- [ ] No se sugiere que los sueños permiten predecir sorteos o mejorar
      probabilidades.
- [ ] No se omiten matices relevantes de S06 o S07.
- [ ] El título no convierte una descripción cultural en una instrucción de
      juego.

## Enfoque por artículo

- **A1:** confirmar que “comunidad rural dominicana” y “comunidades y barrios”
  no se lean como representatividad nacional.
- **A2:** confirmar que el texto describe una práctica y no recomienda una
  técnica para escoger números.
- **A3:** revisar con especial cuidado la relación entre conversación,
  folklore, memoria social y transmisión; evitar inferencias familiares o
  regionales.
- **A5:** verificar el tratamiento respetuoso de suerte, destino, aspiraciones
  económicas y lotería, manteniendo la atribución a los autores.

## Registro de resultado

La persona revisora debe clasificar cada artículo como: `requiere cambios`,
`apto para revisión jurídica` o `no recomendado`. “Apto para revisión jurídica”
no equivale a `approved` ni autoriza publicación.
