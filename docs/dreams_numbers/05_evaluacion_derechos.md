# Evaluación preliminar de derechos

Esta evaluación es documental, no asesoría jurídica. La disponibilidad pública
de una página o PDF no equivale a permiso de reproducción.

## Clasificación

### Uso expresamente autorizado

- **S09:** el repositorio UNAPEC indica CC BY-NC 4.0, salvo contenido señalado
  de otra manera. Permite adaptación y redistribución con atribución para uso no
  comercial. Si la aplicación o su ecosistema tienen finalidad comercial, se
  requiere evaluación adicional o permiso.
- **Datos de resultados de La Banca:** sus términos aplican CC BY 4.0 a lotería,
  sorteo, fecha, números y orden. Esto no cubre la sección de sueños y no
  autoriza reutilizar sus textos comparativos.
  <https://labanca.do/terminos/>

### Uso sujeto a condiciones

- **S06–S08 y S10:** son publicaciones o fondos institucionales accesibles,
  pero no se localizó una licencia abierta que cubra reproducción o adaptación
  extensa. Pueden citarse brevemente con atribución dentro de límites legales;
  una reutilización sustancial requiere revisar copyright, edición y permisos.
- **S11:** el registro BNPHU indica CC BY-NC-ND 3.0 US. Autoriza compartir con
  atribución y sin uso comercial, pero prohíbe distribuir material adaptado.
  No es una base adecuada para derivar fichas modificadas de una aplicación
  comercial sin permiso adicional.

### Permiso no identificado

- **S01–S03:** el sitio ofrece términos generales y un aviso de ausencia de
  garantías, pero no concede licencia para copiar sus tablas o textos.
  <https://www.loteriadominicana.com.do/TermsOfUsage>
- **S12:** no se identificó licencia de reutilización del reportaje.

### Uso restringido o que requiere evaluación

- **S04:** el pie indica “Derechos Reservados”. No se encontró autorización para
  reproducir la tabla completa; requiere permiso del editor MRL Web Management
  o una base jurídica revisada.
- **S05:** los términos excluyen expresamente textos, guías, diseño y código de
  la licencia concedida a resultados. Reutilizar la tabla editorial, análisis o
  redacción requiere permiso o una creación independiente basada en fuentes
  autorizadas.

## Alternativa para un catálogo original

1. Investigar hechos y prácticas desde fuentes académicas/institucionales.
2. Crear redacción, taxonomía y explicaciones propias.
3. Registrar cada afirmación con fuente, localización y fecha de consulta.
4. Incorporar solo asociaciones individuales justificadas, no copiar selección,
   orden, redacción ni estructura expresiva de una tabla ajena.
5. Solicitar permiso escrito para cualquier conjunto sustancial derivado de
   S01–S05.
6. Mantener un registro interno de permisos, alcance, vencimiento y atribución.
7. Someter el catálogo final a revisión legal antes de distribuirlo.

## Contactos y preguntas mínimas

Solicitar a cada titular autorización para reproducción, adaptación,
distribución dentro de aplicaciones móviles, almacenamiento offline, uso
comercial, traducción y actualizaciones. La respuesta debe identificar la obra,
quién concede el permiso y si exige atribución o limitaciones territoriales.
