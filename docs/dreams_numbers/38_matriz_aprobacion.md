## A4

A4 no forma parte del catálogo. Continúa bloqueado porque S07 solo ofrece
respaldo parcial y no se verificó el pasaje previsto de S08. No tiene decisión
favorable ni registro de derechos listo para revisión.

## Condiciones para una decisión futura

1. Identificar de forma verificable la autoría y titularidad de cada redacción.
2. Obtener una revisión cultural independiente sobre precisión y alcance.
3. Obtener una revisión jurídica documentada sobre el uso de hechos y fuentes.
4. Confirmar que la versión revisada no introdujo citas, tablas o material de
   terceros no evaluado.
5. Cambiar estados solamente mediante una decisión editorial explícita y
   trazable.
